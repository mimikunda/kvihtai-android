# KvihtAI Android

Native Material 3 Expressive Android client for interacting with KvihtAI platform stations.

Connects to local tracking stations to provide real-time barbell telemetry, velocity tracking, session logging, and technical lift diagnostics.

---

## Features

- **Material 3 Expressive UI:** Clean, dynamic theming built entirely with Jetpack Compose.
- **Real-Time Telemetry:** Live velocity readout and trajectory plotting via local network discovery.
- **Local-First Data:** Offline caching of session history, individual rep kinematics, and video snippets.
- **Set Diagnostics:** Automated calculation of velocity drop-off, power output, and bar path deviation across multiple reps.
